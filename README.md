# Concord legal

The public, hosted versions of the [Concord](https://github.com/GrantMcCauley/Concord) app's legal documents: Privacy Policy, Terms of Use, Civic Disclosures, and Acknowledgements.

These pages are **generated** from the app's in-app legal text (`src/data/legal.ts` in the app repo) by `scripts/build-legal-pages.ts`, so the hosted and in-app copies never drift. Do not edit the HTML here directly; edit the source in the app repo and regenerate.

Served via GitHub Pages at https://grantmccauley.github.io/concord-legal/
